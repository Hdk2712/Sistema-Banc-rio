# Sistema-Banc-rio
Projeto COBOL

Sobre o projeto:
Este projeto foi desenvolvido com a linguagem COBOL como parte dos meus estudos em programação, com o objetivo de praticar conceitos fundamentais de desenvolvimento de software.

Tecnologias utilizadas:
-COBOL

Funcionalidades:
-Criar uma conta bancária
-Editar conta
-Encerrar conta
-Depósito
-Saque
-Ver saldo
-Download de relatório

Como executar:
-Instale um compilador COBOL compatível, como o DOSBoxPortableCobol
-Clone este repositório
-Compile o programa de acordo com as instruções do compilador
-Execute o programa e siga as orientações exibidas

Aprendizados:
Durante o desenvolvimento, pratiquei lógica de programação, estruturação de código COBOL e resolução de problemas.

Autor:
Estudante de Análise e Desenvolvimento de Sistemas.
